All three IDs and file content identity are frozen before upload; each next stage's path/body is persisted before its request. Commit and delivery retry use exact original strings. Only known completed/blocked receipt clears the import record.
- Upload bytes remain memory-only. On reload, upload requires original-file reselection; SHA-256/name/size must match before reusing the upload key, and server still validates full real content. Another file never overwrites an active intent. File limit is checked before reading: 256 MiB. `ponytail:` documents full-buffer WebCrypto ceiling and future streaming path; another documents full-project in-memory listing ceiling.
- Preview uses actual gateway content with crossOrigin=anonymous, not inline SVG/object/embed. Production/dev CSP adds exact gateway img/media source only; default/script/frame stay restricted. Actual PNG pixels are verified under production Origin.
- Existing M1 CDP runner is factored into built-in-only `webview-cdp.mjs`, reused by new `smoke-m2.mjs`. Runner accepts `-Smoke m1|m2` (default m1), sets child-only profile/data/CDP environment, checks real browser commandline profile, and performs owned normal shutdown/restart. M2 uses same profile across restart and proves persistent marker. `check.ps1` adds Node built-in recovery test; existing full Go server tests provide offline API coverage.
