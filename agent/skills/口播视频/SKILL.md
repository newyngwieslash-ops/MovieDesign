# 口播视频制作方法

## 适用范围
把用户主题、授权素材和明确音轨意图变为一条完整口播视频。每次 Render Attempt 只生成一个覆盖全部 Master Timeline 的候选成片。先查实际能力、参考资产与已有文档，再补齐真正阻塞制作的输入。时长由用户要求与已配置能力共同约束；例如 15 秒口播配音乐必须同时具备 15 秒、参考图、口播和背景音乐能力。

## 不用于
不用于无授权素材、不能满足目标时长或音频需求的配置，也不用于通过多个独立短片拼接伪装完整成片。不得把 LogicalShot 当作独立生成任务；不能裁短、补静帧、消音或悄悄切换模型来规避能力缺口。不得把候选参考的分析结论当作用户已经批准的身份或画风。

## 输入
读取当前项目、现有 Composition/Resource/Version、用户引用的资产 ID、当前所选 Version 及真实媒体分析。整理主题、受众、传播目标、总时长、画幅、口播准确文案或允许创作范围、人物身份、画面风格、需要保留的图像细节、语速、语言、字幕准确文字、口播与背景音乐意图、预算上限和素材授权。已有答案与有效结构化回执直接复用，不能为了走流程重复发问。未确认信息明确标为待定；不要自行编造来源、价格或音频能力。

## 确认门禁序列
1. 意图确认：先回述一条完整片的范围、使用素材与音轨、必要能力。只有确实缺失或存在冲突的项目才询问；展示当前可执行范围，由真实确认卡记录决策。普通聊天、沉默及技能选择都不是后续批准。
2. 脚本确认：提供完整口播台词与节奏、画面职责、准确屏幕文字。计算可行的台词密度并标出不确定处，不把估计语速当实际音频时长。保存脚本文档版本，绑定有效回执后进入分镜。
3. 分镜确认：按 [语义分镜合同](references/storyboard.md) 制作 Panel、LogicalShot、MasterTimeline 和可直接审阅的 storyboard_review.md。明确身份与风格权威引用，逐项描述连续性，展示完整版本并由结构化卡绑定 storyboard_revision。可选预览图不能代替文本语义权威，也不是必须生成的额外付费步骤。
4. 精确 Prompt 与费用：根据已批准分镜编译完整 Prompt 合同，明确能力、参数、参考槽位、音频意图、报价版本及预算。展示给用户的字符串与提交生成的字符串逐字一致，不摘要后替换。执行 [Preflight](references/preflight.md)，只使用实际存在的结构化合同与费用回执。若应用尚未提供相应语义门禁/合同能力，说明缺口并停在文档准备阶段，不声称方法说明本身已构成后端批准。
5. 生成与交付：只提交该冻结合同的一次完整 Render Attempt；等待使用受管任务查询。通过统一投递登记 Version、来源与资产，展示真实 task/version/asset 身份和可播放结果。交付成功、任务完成与用户验收分别陈述。

上游主题、脚本、身份、风格、Panel、LogicalShot 或 MasterTimeline 的语义变化会使依赖的下游批准失效，重新确认受影响的环节。只有模型合法参数、参考槽位或 Prompt 措辞变化且语义未变时，保留语义批准，但必须生成新 Prompt 合同及报价并取得对应批准。不得借复用回执跨越 revision 或报价版本；恢复同一任务时复用仍有效回执，不重复问已答项。

## 产物
保存可追溯的意图与脚本文档、完整语义分镜包、精确 Prompt 合同、Preflight 结果及人类批准回执。生成产物是一条完整视频及其新 Version，关联原参考、脚本、storyboard_revision、合同和 task。独立成果建立独立 Resource；修订同一内容沿用 Resource 并创建 Version，不覆盖旧版本。客观媒体检查可以报告时长、尺寸和音轨存在性，不能代替用户的质量验收。

## 失败回流
按原任务返回原始问题的可安全展示信息、失败阶段、状态与已知计费情况。能力或素材缺口回到对应输入；语义变更回到受影响的批准；纯执行参数变更回到新合同和费用确认。失败由用户决定是否重试或改需求，禁止自动重试、切换配置、补拍或拼接。unknown 只重放既有回执或只读对账，不再次发送生成；对账仍未知时保持未知。不得自行评判自身成片质量并重新生成，验收意见和是否生成新版本由用户给出。
