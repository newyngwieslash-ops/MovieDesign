# 生成前检查

对照实际能力元数据确认目标时长、画幅、引用数量/类型、视频参考和口播/音乐能力。素材必须属于本项目，资产存在且授权明确；仅传 ID，不传本地路径。身份、风格和色彩权威需要来自明确的授权资产或已交付生成资产，不从候选参考分析自动升级。

15 秒人声口播配背景音乐合同（`duration: 15`、`generate_audio: true`、`audio_mode: "narration+music"`）必须由单一配置的 `video:{id}`（`ark-video`）模型一次性生成整条带音轨的视频，不隐式调用第三方 TTS 或音乐模型，也不把多个 `LogicalShot` 拆成片段拼接。若能力不支持 `audio`、声明的 `duration_seconds` 不含 15 秒、或参考图超出 `max_references`，必须在生成与计费前通过 Preflight 阻断并返回可操作缺项。

核对脚本与分镜语义批准仍有效，storyboard_revision、引用 Version、Prompt 合同、能力与配置版本一致。参数只能包含该能力声明的平铺字段；媒体内容只进入 references。确认完整 Prompt 精确字符串已展示，口播、音乐、时段与连续性都有表达，未遗失用户要求。任何不可表达的能力缺项必须阻止生成并说明。

报价应包含原币、估算口径、来源和版本，不把未知价当免费。费用回执必须对应本次合同及报价；新 Prompt 或参数生成新合同和新报价。每次提交只产生一条完整候选视频；不按 Shot 发起子视频。任务状态 unknown 只查询与对账，绝不重发；failed/cancelled 的后续动作由用户决定。产物下载后仅由网关执行容器格式（`ftyp`/`moov`/`mdat`）、尺寸、时长容差（编码时间基与帧容差内，拒绝显著短片）及音轨存在性的客观技术校验，落入目标 Composition/role 并登记 Resource 新 Version 与完整 SQL 血缘，等待用户验收，不执行 LLM 主观自评或自动付费重生成。
