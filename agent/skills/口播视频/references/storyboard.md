# 语义分镜合同

语义分镜是可审阅的制作文件，不是提示词缩写，也不是模型专属九宫格语法。数量依叙事实际需要，不固定五个 Panel、三个 Shot 或任何字数预算。

每个 Panel 至少明确：稳定 ID、MasterTimeline 内的时间点、景别、构图与视线、主体及动作进度、身份/服装/道具连续性、当下口播或屏幕文字、与相邻 Panel 的转场依据。时间点表示叙事状态，不能自动等同一个视频片段。转场依据须说明为什么叙事或运动允许此变化。

每个 LogicalShot 至少明确：稳定 ID、起止时间范围、包含的 Panel、叙事职责、起始状态与结束状态、连续动作及镜头运动、与下个 Shot 的衔接。LogicalShot 是一条完整视频 Prompt 的章节，不是独立视频资产。时间范围需覆盖所含 Panel，不能重叠矛盾或产生未说明的空段。

MasterTimeline 至少明确：总时长、按时间排序的 LogicalShot、整体叙事弧线、口播准确台词及对应时段、音乐情绪与进入/退出/衰减意图、口播和背景音乐的关系、是否包含其他声音、字幕与准确文字、首尾状态。音轨意图必须能由所选实际能力实现，不能把“配音乐”遗漏成纯画面。

storyboard_review.md 完整展示上述三层、引用资产/Version、身份与风格权威、待定项以及当前 storyboard_revision。必须让用户读懂整条片如何展开，再获取绑定该 revision 的结构化回执。可选分镜预览只辅助阅读，不覆盖语义文件。修改任一语义字段会产生新 revision，旧分镜及其下游批准不能用于新版本。
