# 区域意图与版本依据

标注是用户对真实源图的结构化说明。保留 asset ID、sourceVersionID、原图尺寸、坐标系、形状和文字原文。矩形、箭头或笔画指向对象/区域，需结合用户文字解释，不擅自将一个框理解成严格像素遮罩。说明选择的是移除、替换、修复还是保留，并说明对邻近内容和整体风格的允许影响。

同一图片的不同 Version 可能有不同构图或尺寸。标注只对其原始版本有效；来源变动时先让用户确认重定位或重新标注，不直接按旧坐标执行。多条标注冲突时列出冲突请用户决定；不得挑选其一而忽略其他条目。没有标注也可使用用户清晰描述的区域，但必须如实写明它是语义定位。

输入槽位中只放实际登记的参考资产 ID。若所选供应商只支持参考图加文字，则方案明确说明修改范围为意图约束，无法保证框外像素完全不变。只有能力与已实现传输确实支持 mask 时才承诺相应能力；本方法不自行引入路径、文件读取或新 mask 协议。

交付后用统一对象关系保存新版本、源版本和资产。不要把旧图用文件覆盖“修好”，也不要因为自动视觉比较觉得不够好而重新付费生成。客观缺文件、尺寸错误或供应商失败按真实问题报告，下一步由用户决定。
