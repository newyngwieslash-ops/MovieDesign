# 图片标注修复方法

## 适用范围
围绕一张真实授权参考图及用户区域意图修订内容，形成同一 Resource 的新 Version，并保留源版本血缘。适用于替换对象、修复局部表现、保留关键主体的调整。读取已有版本、图像尺寸和标注，再判断实际图像编辑能力能否表达该请求。

## 不用于
不用于无参考资产的纯文生图、未获授权素材或实际不支持参考图编辑的配置。不把画布框选、矩形坐标或文字区域描述冒充供应商接受的精确 mask；未实现 mask 传输时不得保证框外像素不变。不能悄悄转为纯文生图、改用另一张参考、覆盖源资产或自动反复修图。

## 输入
确认项目、参考 asset ID、sourceVersionID、归属 Resource、图像尺寸、用户所选当前版本、每条标注的几何形状和文字说明。按 [区域意图规则](references/annotations.md) 理解目标与保留要求，区分需要改的内容、不能改的内容和允许整体调整的部分。读取已有有效回执与已答问题，只询问仍阻塞的冲突或缺项。

## 确认门禁序列
1. 引用/区域意图确认：展示源图与明确版本，逐条复述区域指向和修改目的，指出范围描述能力的限制。若引用与标注来源不一致，先停止并请用户明确版本；不能把坐标静默套到另一张图。使用真实结构化回执确认，不将普通聊天或选择技能当批准。
2. 编辑方案确认：给出具体修改、保留项、预期可能影响的邻近内容和所需实际能力，列出每条标注如何落实。通过现有 question 确认卡完整展示来源版本、方案和准确编辑 Prompt 与 references 的对应关系，取得真实人类回执；不在执行时摘要改写。随后使用现有冻结生成请求与费用回执，不要求另建图片语义合同服务，也不能声称尚未实现的后端语义门禁已锁定方案。
3. 费用确认：核验所选配置支持编辑、引用格式和参数；参数只用能力声明的平铺字段，引用只传受管 ID。展示原币费用、估算来源和版本以及准确 Prompt。未知价阻止生成，不能当免费。用户通过对应费用卡批准本次冻结输入后才提交。
4. 生成版本：一次提交对应一次受管任务；在原 Resource 下创建新 Version，source_version_id 指向确认的源版本。通过统一投递登记资产并展示新旧版本和任务状态；不得覆盖原文件或擅自切换用户当前版本。

更换源图、修改区域目标或保留要求属于上游语义变化，会使下游方案和生成批准失效。只有合法参数、槽位或 Prompt 措辞调整且语义不变时保留语义批准，但必须生成新 Prompt 合同和新报价并取得相应批准。已确认事项用仍有效的回执复用，不重复问已答项，不跨来源版本或合同复用过期回执。

## 产物
留下引用与标注来源记录、可审阅编辑方案、精确 Prompt 合同、能力检查和费用回执。最终交付一张真实生成图像和新 Version，记录 source_version_id、task、asset 与原 Resource。客观尺寸/格式检查可以报告；内容是否达到修复目标由用户验收，不能把任务成功说成用户已经满意。

## 失败回流
报告原问题、失败阶段和已知任务/计费状态，不掩饰为“优化中”。引用或区域冲突回到意图确认，语义变更重走受影响的批准，参数调整产生新合同与报价。失败由用户决定重试、调整或停止；unknown 只重放回执/只读对账，不新建生成任务。不得自行评判自己的修图质量并再次生成，不能在未授权情况下自动重试、换模型或另造资产。
